# ASKRY GYM – نظام إدارة النادي

## الرفع (اختار طريقة واحدة)
**1) Netlify (الأسهل – 2 دقيقة):** افتح app.netlify.com/drop واسحب فولدر `askry-gym-hosting` كله. هتاخد لينك فوراً. من Domain settings تقدر تربط دومين خاص (مثل askrygym.com).
**2) Cloudflare Pages:** Workers & Pages ← Create ← Upload assets ← ارفع الفولدر.
**3) GitHub Pages:** ارفع الملفات في Repository وفعّل Pages من Settings.

لازم الموقع يكون على HTTPS (كل الخدمات فوق بتوفره تلقائياً).

## التثبيت كتطبيق
افتح اللينك على الموبايل ← أندرويد: ⋮ ثم Install app | آيفون (Safari): مشاركة ثم Add to Home Screen.
بعد أول فتح بيشتغل حتى من غير إنترنت.

## مهم
- البيانات بتتخزن في متصفح الجهاز نفسه. كل جهاز له بياناته. استخدم زرار 💾 نسخة احتياطية في تبويب المالية بانتظام، و📂 استرجاع لنقلها لجهاز تاني.
- كلمة المرور بتتحدد أول مرة تفتح النظام، ومفيش استرجاع لها لو نسيتها (امسح بيانات الموقع من المتصفح لإعادة الضبط، وده بيمسح البيانات، فاحتفظ بنسخة احتياطية).
- لربط كل الأجهزة بنفس البيانات لحظياً يلزم قاعدة بيانات سحابية.
